## What is Hello World?

"Hello, World!" is traditionally the first program or file created when learning a new programming language or setting up a new project. It serves as a simple sanity check to confirm that everything is working correctly.

## Why Hello World?

- It's a time-honoured tradition in software development
- It verifies that your environment is set up correctly
- It's the simplest possible starting point for any project
- First introduced in Brian Kernighan's 1972 guide to the B programming language
