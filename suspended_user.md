# Suspended User

This file contains information related to suspended users.

## Overview

A suspended user is an account that has been temporarily or permanently disabled, restricting the user's ability to access systems, applications, or services.

## Common Reasons for Suspension

- Violation of acceptable use policy
- Suspicious or unauthorized activity detected
- Failed security checks or compliance requirements
- Administrative action pending investigation
- Inactive account flagged for review

## Suspension Process

1. **Detection** – A trigger event is identified (e.g., policy violation, security alert).
2. **Review** – The account is flagged and reviewed by an administrator.
3. **Suspension** – Access is revoked across all connected systems.
4. **Notification** – The user and relevant stakeholders are notified.
5. **Resolution** – The account is either reinstated or permanently deactivated based on the outcome.

## Impact of Suspension

- Loss of access to applications and services
- Active sessions are terminated
- SSO and MFA tokens are invalidated
- Device enrollment may be revoked (MDM/EDR)

## Reinstatement

Suspended users can be reinstated after a review process confirms the issue has been resolved. Reinstatement typically involves:

- Identity verification
- Re-enrollment in MFA
- Conditional access policy re-evaluation
- Audit log review
